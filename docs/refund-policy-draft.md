# 환불 정책 초안 (결제 연동 시 공개)

> 상태: 초안. 결제 연동 전에 법률 검토를 받은 뒤 `/refund` 페이지로 공개하고, 결제 버튼 바로 위에 요약을 보여준다.
> 근거로 삼은 원칙: 전자상거래법상 디지털 콘텐츠는 제공이 시작되면 청약철회를 제한할 수 있으나, 그 사실을 결제 전에 명확히 알리고 체험(무료 검사·봉인 챕터 미리보기)을 제공해야 한다.

## 1. 전액 환불
- 결제 후 **추가 질문에 답하기 전**이라면, 결제일로부터 7일 이내에 전액 환불합니다.
- 결제는 됐는데 **리포트가 만들어지지 않거나 열리지 않는 경우**, 기간과 관계없이 전액 환불합니다.
- 리포트 내용이 **결제 전 안내와 현저히 다른 경우**, 안 날로부터 3개월 이내(늦어도 결제일로부터 30일 이내) 전액 환불합니다.

## 2. 환불이 제한되는 경우
- 추가 질문을 마치고 **리포트가 만들어져 열람이 시작된 뒤**에는, 디지털 콘텐츠 특성상 단순 변심에 의한 환불이 어렵습니다.
- 이 사실은 결제 버튼 바로 위에 굵게 표시하고, 결제 전에 체크로 확인받습니다.
  - 예) "□ 추가 질문을 마치면 리포트가 바로 만들어지며, 이후에는 단순 변심으로 환불할 수 없음을 확인했습니다"

## 3. 묶음 상품
- 찾기·잘하기 묶음은 두 리포트 중 **아직 만들어지지 않은 쪽**의 금액(단품가 기준)을 환불합니다.

## 4. 미성년자
- 만 19세 미만이 법정대리인 동의 없이 결제한 경우, 본인 또는 법정대리인이 결제를 취소할 수 있습니다.
- 출시 초기에는 고등학생 버전을 유료로 열지 않거나, 결제 전 보호자 동의 절차를 둡니다.

## 5. 요청 방법과 처리 기간
- 결제 내역(주문 번호 또는 결제 일시·금액)과 함께 core-trait@naver.com으로 요청합니다.
- 환불이 확정되면 3영업일 안에 결제 수단으로 취소합니다. 카드사·결제대행사 사정에 따라 실제 반영까지 시간이 더 걸릴 수 있습니다.

## 결제 연동 시 구현 체크리스트
- [ ] 결제 버튼 위: 가격, 제공 내용(챕터 목록), 환불 제한 요약 + 확인 체크박스
- [ ] `orders` 테이블: 결제 완료(paid) 전에는 리포트 API가 404/402를 돌려주도록
- [ ] 리포트 최초 열람 시각 기록 (환불 가능 여부 판단 근거)
- [ ] 판매자 정보 표시 (운영자명, 연락처 — 사업자 등록 후 사업자 정보로 교체)
- [ ] 소득 신고 대비 매출 기록 내보내기 (관리자 화면)
