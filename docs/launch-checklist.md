# 출시·광고 점검표 (2026-10-06)

결제를 붙이고 광고를 돌리기 전에 확인할 것들. 위에서부터 순서대로.

## 1. 검색 등록 (본인 계정 필요, 각 10분)

검색에 나오려면 사이트 주인임을 인증하고 사이트맵을 제출해야 한다. 인증 코드는 파일을 고치지 않고 Vercel 환경변수로 넣는다.

### 네이버 서치어드바이저 (searchadvisor.naver.com)
1. 로그인 → 웹마스터 도구 → 사이트 추가: `https://core-trait.com`
2. 소유 확인 방법에서 **HTML 태그** 선택 → `content="..."` 안의 값만 복사
3. Vercel → 프로젝트 → Settings → Environment Variables에 `NAVER_SITE_VERIFICATION` = 복사한 값 (Production) 추가 → 재배포
4. 서치어드바이저로 돌아와 **소유 확인** → 요청 → 사이트맵 제출: `https://core-trait.com/sitemap.xml`

### 구글 서치 콘솔 (search.google.com/search-console)
1. 속성 추가 → **URL 접두어** → `https://core-trait.com`
2. **HTML 태그** 방법 → `content="..."` 값 복사
3. Vercel 환경변수 `GOOGLE_SITE_VERIFICATION` = 복사한 값 → 재배포
4. 확인 → Sitemaps → `sitemap.xml` 제출

재배포는 Claude에게 "환경변수 넣었어, 재배포해 줘"라고 하면 된다. 검색에 실제로 잡히기까지는 며칠~몇 주 걸린다.

## 2. 광고 링크 만드는 법

광고·홍보 글에 넣는 링크 끝에 아래를 붙이면, 관리자 화면 **"유입과 공유 → 유입 경로별 성과"**에 경로별로 방문·시작·완료가 따로 보인다.

```
https://core-trait.com/?utm_source=instagram&utm_medium=paid&utm_campaign=launch_a
```

| 항목 | 넣는 값 | 예 |
|---|---|---|
| `utm_source` | 어디서 왔나 | `instagram`, `everytime`, `reddit`, `kakao` |
| `utm_medium` | 유료/무료 | `paid`, `post`, `dm` |
| `utm_campaign` | 광고 소재·글 이름 | `launch_a`, `sage_card`, `compare_hook` |

- 광고 소재마다 `utm_campaign`을 다르게 주면 어떤 소재가 **완료까지** 이어지는지 비교할 수 있다. 클릭 수가 아니라 완료율로 판단할 것.
- 도착 페이지는 두 가지를 비교해 볼 만하다: 메인(`/`)과 검사 바로 시작(`/hexaco-test?start=1&utm_...`).
- 영어판은 유럽 기준에 맞춰 **동의한 사람만** 기록된다. 그래서 영어판의 "방문" 수는 실제 클릭보다 적게 나온다(광고 플랫폼의 클릭 수와 함께 볼 것).

## 3. 광고 문구에서 피할 것

- 메타(인스타·페이스북)는 **개인 특성을 단정하는 문구**를 금지한다. "당신은 불안한 사람인가요?", "외로우신가요?"처럼 보는 사람의 상태를 짚는 표현은 반려 사유다. → "내 원형은 뭘까?", "22가지 원형 중 하나" 같은 호기심형으로.
- "정확한 진단", "과학적으로 검증된" 같은 표현 금지. 결과 화면에도 "대규모 검증 전"이라고 밝히고 있다.
- 타깃 연령은 만 18세 이상 권장(한국어판 이용 연령은 14세 이상이지만, 결제가 붙으면 미성년자 결제 문제가 생김).

## 4. 예산 감 잡기

관문 지표는 **14일 안에 검사 완료 100명**이 있어야 판단할 수 있다. 실제 비율은 돌려 봐야 알지만 계산은 이렇게 한다.

```
필요한 클릭 수 = 100 ÷ (시작률 × 완료율)
예) 시작률 40%, 완료율 60% → 100 ÷ 0.24 ≈ 420 클릭
클릭당 200~500원이면 약 8만~21만 원
```

먼저 2~3만 원으로 소재 2~3개를 돌려 시작률·완료율을 확인한 뒤, 잘 되는 소재에만 나머지를 쓰는 걸 권한다.

## 5. 광고 전에 직접 확인할 것

- [ ] 휴대폰으로 검사 끝까지 한 번 (한국어)
- [ ] 결과 리포트에서 **이미지로 저장**, **친구와 비교하기** 버튼 눌러 보기
- [ ] 받은 비교 링크를 다른 휴대폰(또는 시크릿 창)에서 열어 검사 → 비교 결과까지
- [ ] 카톡에 `core-trait.com/a/sage` 붙여 미리보기 이미지 확인
- [ ] 관리자 화면: 맨 위 "저장 정상" 표시, 한국어판/영어판 전환, "유입과 공유" 섹션
- [ ] 진로 리포트(`/career`) 한 번 끝까지 + 샘플 리포트(`/career/samples`) 읽어 보기
- [ ] GitHub 저장소 비공개 전환

## 6. 결제 붙일 때 할 일 (서류 통과 후)

1. 페이앱 연동: 결제 요청 → 결제 완료 통지(서버) → `orders` 기록
2. `/api/career/start`에서 결제 완료된 주문인지 확인 (지금은 관리자 비밀번호로만 잠겨 있음)
3. `proxy.ts`에서 `/career` 잠금 해제
4. 이용약관에 유료 서비스·환불 조항 추가 (`docs/refund-policy-draft.md` 초안), 결제 화면에 환불 조건 고지
5. 무료 결과 화면의 "출시 알림 받기"를 "진로 리포트 받기"로 교체
6. 묶음 가격 결정
